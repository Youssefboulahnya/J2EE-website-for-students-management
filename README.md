# J2EE-website-for-students-management
A university project about managing students made with the J2EE

### About
a website that lets you manage students, it requires a login of the admin (username: admin, password: admin123) to visualize a list of students that we fetch from a connected data base letting you create a new student, modify an existed student and delete a student, all these actions will have effect on the content of the data base.

### Requirements
This project was built using **Java EE** with **Eclipse** as the IDE and **XAMPP** as the local server environment (Apache + MySQL). To run it, you'll need Eclipse (with Java EE / Web Tools support), a servlet container such as **Apache Tomcat** configured in Eclipse, XAMPP with MySQL running, and the MySQL JDBC driver added to the project's build path. Before running the project, import the database schema from `database/database.sql` into MySQL via phpMyAdmin, and make sure the database connection settings in the source code match your local setup.
